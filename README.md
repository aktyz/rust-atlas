# 🗺️ Rust Atlas

> A growing map of Rust concepts, experiments, and projects explored along the journey of learning Rust.

## About

**Rust Atlas** is my personal repository for exploring the Rust programming language through hands-on practice.

The goal is to build a strong and structured foundation in Rust by combining:

- 📚 Theory and language fundamentals
- 🧪 Small experiments exploring Rust concepts
- 🛠️ Practical projects
- 🔍 Notes and discoveries from the Rust ecosystem

This repository is not just a collection of exercises — it is a living map of my progress toward becoming productive with Rust, with a focus on areas where Rust excels:

- Systems programming
- Performance-oriented software
- Backend development
- Blockchain and Solana development

A strong understanding of Rust fundamentals is the foundation for effectively working with Solana programs and its ecosystem, where concepts such as ownership, memory safety, serialization, and low-level performance considerations are essential.

## Learning Goals

Through this repository, I aim to develop a deep understanding of:

### Rust Fundamentals

- Rust syntax and idiomatic patterns
- Ownership and borrowing model
- Memory safety without garbage collection
- Structs, enums, and pattern matching
- Error handling
- Traits and generics
- Lifetimes
- Collections and iterators

### Advanced Rust Concepts

- Concurrency and parallel programming
- Async Rust
- Serialization and data modeling
- Performance considerations
- Rust ecosystem and tooling
- Writing maintainable and idiomatic Rust code

### Solana Development Foundation

- Understanding how Rust is used in Solana programs
- Working with Solana's programming model
- Exploring smart contract concepts
- Learning how blockchain constraints influence software design
