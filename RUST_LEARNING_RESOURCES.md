# Rust Learning Resources

> The single best free online resource to start learning Rust is **The Rust Programming Language** (commonly called **"the Book"**). It is the official, comprehensive, and beginner-friendly guide maintained by the Rust team, and it's the resource most Rust developers recommend as the starting point.

**Official Book:** https://doc.rust-lang.org/book/

---

# Top Free Rust Resources

## 1. 📘 The Rust Programming Language ("the Book")

**Description**

The official Rust tutorial covering everything from the language fundamentals to advanced concepts including:

- Variables and data types
- Functions
- Structs and enums
- Ownership
- Borrowing
- Lifetimes
- Traits
- Error handling
- Concurrency
- Smart pointers
- Testing
- Cargo ecosystem

**Best for**

Anyone with prior programming experience who wants a solid foundation in Rust.

**Link**

https://doc.rust-lang.org/book/

---

## 2. 🦀 Rustlings

**Description**

A hands-on command-line course consisting of dozens of small broken Rust programs that you fix to learn the language.

Instead of only reading, you'll actively solve exercises covering:

- Variables
- Functions
- Ownership
- Borrowing
- Collections
- Enums
- Traits
- Error handling
- Iterators
- Macros

**Best for**

Learning by doing. Ideal alongside or immediately after reading the Book.

**Link**

https://github.com/rust-lang/rustlings

---

## 3. 💡 Rust by Example

**Description**

A collection of short, runnable examples organized by topic.

Excellent when you need to quickly see:

- syntax
- idiomatic patterns
- practical examples

without reading long explanations.

**Best for**

- Practice
- Quick reference
- Looking up language features

**Link**

https://doc.rust-lang.org/rust-by-example/

---

## 4. 🎓 Comprehensive Rust (Google)

**Description**

A free Rust course originally developed for Google's engineers.

Topics include:

- Ownership
- Generics
- Traits
- Error handling
- Async programming
- Lifetimes
- Smart pointers
- Concurrency

The material is presented as a structured course with slides and exercises.

**Best for**

People who prefer a classroom/course-style learning experience.

**Link**

https://google.github.io/comprehensive-rust/

---

## 5. 🌟 Blessed.rs Learning Resources

**Description**

A curated collection of high-quality Rust learning materials and ecosystem recommendations.

Resources are clearly marked as:

- Free
- Paid

Useful once you've mastered the fundamentals and want to explore specialized topics.

**Best for**

Finding the next learning resource after completing the basics.

**Link**

https://blessed.rs/learning-resources

# Recommended Learning Path

## Phase 1 — Learn the Fundamentals

Read **The Rust Programming Language**.

Focus on Chapters **1–6**, covering:

- Installation
- Cargo
- Variables
- Functions
- Ownership
- Borrowing
- References
- Structs
- Enums
- Collections

These chapters introduce Rust's most important concepts, especially ownership and borrowing.

---

## Phase 2 — Reinforce Through Practice

Complete **Rustlings** exercises alongside the Book or immediately afterward.

The exercises help transform theoretical knowledge into practical experience.

---

## Phase 3 — Use Rust by Example as Your Reference

Whenever you're unsure how to implement something:

- search Rust by Example
- copy a small example
- experiment with it

This is much faster than rereading entire chapters.

---

## Phase 4 — Build Something Small

Choose a simple project such as:

- CLI application
- To-do list
- File organizer
- JSON parser
- HTTP client
- Basic web server

Learning accelerates dramatically once you're solving real problems.

---

## Phase 5 — Continue Learning

Once you're comfortable with the basics:

- Read the Rust Standard Library documentation.
- Explore **Blessed.rs** for ecosystem recommendations.
- Learn popular crates such as:
  - `serde`
  - `tokio`
  - `clap`
  - `reqwest`
  - `axum`

---

# Suggested Study Order

1. 📘 The Rust Programming Language
2. 🦀 Rustlings
3. 💡 Rust by Example (reference)
4. 🎓 Comprehensive Rust (optional deeper course)
5. 🌟 Blessed.rs (advanced learning)

---

# Final Recommendation

If you're learning Rust from scratch and already have programming experience:

- **80% of your learning time:** The Rust Programming Language
- **20% of your learning time:** Rustlings

After finishing Chapters **1–6** and the corresponding Rustlings exercises, start building a small project. Real-world practice is the fastest way to internalize Rust's ownership model and become productive.
